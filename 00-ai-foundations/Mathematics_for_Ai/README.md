
## Mathematics for AI — Topic Map

| **Area**           | **Topic / Subtopic**           | **Why it matters in AI/ML**                                                             |
| ------------------ | ------------------------------ | --------------------------------------------------------------------------------------- |
| **Linear Algebra** | **Vectors**                    | Represent data, features, embeddings, images, etc.                                      |
|                    | **Matrices**                   | Represent datasets and neural-network weights.                                          |
|                    | **Matrix Multiplication**      | Used heavily in neural-network forward passes and transformations.                      |
|                    | **Dot Product**                | Used for similarity, recommendation systems, and attention mechanisms.                  |
|                    | **Norms**                      | Used for distances, regularization, and algorithms such as KNN.                         |
|                    | **Matrix Transformations**     | Used for projections, transformations, and representation changes.                      |
|                    | **Eigenvalues & Eigenvectors** | Important for PCA and finding important directions in data.                             |
|                    | **Eigen Decomposition**        | Used in PCA and covariance-matrix analysis.                                             |
|                    | **SVD**                        | Used in dimensionality reduction, recommendation systems, image compression, and NLP.   |
| **Calculus**       | **Derivatives**                | Understand how a function/loss changes when a parameter changes.                        |
|                    | **Partial Derivatives**        | Handle functions with multiple parameters.                                              |
|                    | **Chain Rule**                 | Core mathematical idea behind backpropagation.                                          |
|                    | **Gradients**                  | Tell us how the loss changes with respect to model parameters.                          |
|                    | **Gradient Descent**           | Used to update model parameters to minimize loss.                                       |
|                    | **Jacobian**                   | Represents derivatives of multivariable/vector-valued functions; useful in advanced ML. |
|                    | **Hessian**                    | Describes second-order curvature; used in advanced optimization.                        |
| **Probability**    | **Conditional Probability**    | Foundation for models such as Naive Bayes and Bayesian networks.                        |
|                    | **Bayes' Theorem**             | Used in Bayesian reasoning and probabilistic models.                                    |
|                    | **Random Variables**           | Mathematically represent uncertainty in data.                                           |
|                    | **Probability Distributions**  | Model how random variables behave and are distributed.                                  |
|                    | **Expectation**                | Used to reason about average/expected outcomes and loss.                                |
|                    | **Variance**                   | Measures spread and is important for understanding model behavior.                      |
|                    | **Likelihood**                 | Important for parameter estimation and probabilistic models.                            |
|                    | **MLE & MAP**                  | Methods for estimating model parameters.                                                |
| **Statistics**     | **Sampling**                   | Foundation for working with samples, train/test splits, cross-validation, etc.          |
|                    | **Correlation**                | Helps understand relationships between variables/features.                              |
|                    | **Bias & Variance**            | Helps understand underfitting and overfitting.                                          |
|                    | **Hypothesis Testing**         | Used to test whether observed differences may be statistically meaningful.              |
|                    | **Confidence Intervals**       | Quantify uncertainty around estimated values/metrics.                                   |
|                    | **Statistical Significance**   | Helps assess whether an observed result could plausibly be due to chance.               |
| **Optimization**   | **Optimization Basics**        | Understand how ML models find parameter values that minimize/maximize an objective.     |
|                    | **Convex Optimization Basics** | Helps understand optimization problems with useful global-optimum properties.           |
|                    | **Gradient Descent**           | Fundamental optimization method used in ML.                                             |
|                    | **SGD**                        | Stochastic version of gradient descent, widely used in ML/deep learning.                |
|                    | **Learning Rate**              | Controls the size of parameter updates during training.                                 |
|                    | **Adam**                       | Adaptive optimization algorithm widely used in deep learning.                           |
|                    | **Loss Landscapes**            | Helps understand how optimization behaves around minima and saddle points.              |
|                    | **Regularization**             | Controls model complexity and helps reduce overfitting.                                 |
|                    | **Constraints**                | Important in constrained optimization problems such as SVMs.                            |
