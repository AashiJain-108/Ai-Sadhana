# Supervised Learning

<img width="450" height="257" alt="image" src="https://github.com/user-attachments/assets/d81a05e7-78dc-48c9-a34c-910b1e624781" />

- Supervised learning is a type of machine learning where the model learns fromlabelled data, which means that the input data is accompanied by the correct output.
- In supervised learning, the algorithm learns to map input data to output labels basedon example input-output pairs provided during the training phase.
- The goal of supervised learning is to learn a mapping function from input variables to output variables so that the model can make predictions on unseen data.
- Examples of supervised learning algorithms include linear regression, logistic regression, decision trees, support vector machines (SVM), and neural networks.
