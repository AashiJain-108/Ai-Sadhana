| Aspect | Classification | Regression |
|---|---|---|
| Output | Discrete categories | Continuous numbers |
| Example | "Is this dog or cat ?" | "What will the house price be?" |
| Output space | A set of predefined classes (e.g., cat, dog) | Any real number within the model's output range |
| Loss function | Cross-entropy | Mean Squared Error (MSE), Mean Absolute Error (MAE) |
| Evaluation metric | Accuracy | MSE, MAE, \(R^2\) |
| Decision / Model output | Boundaries between classes | A curve that fits the data |
| Main question | "Which category?" | "How much?" |
|Algorithms| Naīve Bayes, K-NN,SVM, Decision Trees, Logistic Regression |Linear Regression, Polynomial Regression, Ridge/Lasso Regression |
