# Optimization

**Decision-making — Optimization**

We define a measure of prediction error and find the model parameters that minimize it.

For example, mean squared error:
$$\[
\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]$$

The best line under this criterion is the one with the lowest average squared prediction error on the training data.
