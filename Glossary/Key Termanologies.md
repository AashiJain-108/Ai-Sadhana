# KEY TERMANOLOGIES 

---

| Term | Hype | Reality | Explain Like I'm Five |
| --- | --- | --- | --- |
| **Model** | "The AI mind" | A mathematical function with learnable parameters mapping inputs to outputs | A magic recipe box that takes in ingredients (data) and spits out a finished dish (answers) |
| **Training** | "Teaching the AI to think" | Running an optimization algorithm to minimize error across a dataset / Running an optimization algorithm to adjust model parameters so predictions match known outputs | Practicing a video game level over and over until you stop making mistakes |
| **Feature** | "An input column" | A measurable property of data used as an independent variable in prediction | The clues you give a detective—like hair color, height, and shoe size—to help them guess who did it |
| **Label** | "The answer sheet" | The target variable representing known outputs in supervised training data | The picture on the front of a jigsaw puzzle box so you know what you’re trying to build |
| **Hyperparameter** | "A secret setting" | Configuration variables set before training that control model optimization | The oven temperature and timer set before baking—you can't change them once the cake is inside |
| **Loss Function** | "Measuring intelligence" |  A function that measures the difference between predicted and actual outputs, which training tries to minimize. | A scorecard that tells you how many steps you missed the target target mark by |
| **Overfitting** | "It memorized the test" | A high variance state where noise in training data is captured instead of general patterns | A kid who memorized answer choices A, B, C for a test, but panics when the teacher changes the questions |
| **Underfitting** | "It didn't learn anything" | High bias condition where the model capacity is insufficient for pattern complexity | Trying to draw a detailed portrait using only a thick crayon—it’s too simple to get the details |
| **Generalization** | "It works everywhere" | The statistical ability to perform accurately on unobserved data drawn from the same distribution | Practicing soccer in your backyard and still playing well when you go to a brand-new field |
| **Cross-validation** | "Testing on different chunks" | Resampling technique partitioning data into folds to reliably estimate model stability | Splitting your study group into teams and testing each other on different chapters so no one cheats |
| **Regularization** | "Keeping weights small" | Modifying the loss function with penalty terms to prevent coefficient growth | Putting training wheels on a bike so the rider doesn't lean too far in one direction and fall |
| **Data Drift** | "The world changed" | Shift in statistical distribution of independent variables over time causing performance loss | Learning all the rules to a game, but waking up tomorrow to find out the rules were changed |
